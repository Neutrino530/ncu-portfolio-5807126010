## 一、这个仓库是干什么的

这里存放我本学期**每一周的课程实验**：代码、数据说明、运行结果与实验报告。
每周一个独立文件夹，按时间顺序排列，既是交作业的地方，也是我一步步成长的记录。

可以理解为：一本**会自动盘点、永远不会丢、还能倒带重来的实验记录本**。

## 三、每周 Git 提交流程（给零基础的自己看）

```bash
# 1. 拉取远端最新版本，避免冲突
git pull

# 2. 查看自己改了哪些文件
git status

# 3. 把改动加入"待提交清单"
git add week05/

# 4. 提交到本地仓库，附一句说明
git commit -m "docs(week05): 补充单摆模拟实验报告"

# 5. 推送到 GitHub
git push
```

**提交信息推荐格式**：`类型(范围): 简短说明`

| 类型 | 含义 |
| :--- | :--- |
| `feat` | 新增功能或新增实验代码 |
| `fix` | 修复错误 |
| `docs` | 只改了文档/报告 |
| `refactor` | 重写代码但结果不变 |
| `test` | 添加测试 |

## 四、重要提醒

1. **绝对不要把**密钥、密码、`.env` 文件、`node_modules/`、虚拟环境提交进来 —— 它们已在 `.gitignore` 中被屏蔽。
2. 单个文件大小控制在 **100 MB 以内**；超过请用外链或 Git LFS。
3. 一周一提交，不要攒到最后一次性推送。
